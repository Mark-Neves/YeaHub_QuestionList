📚 Interview Questions App

Приложение для подготовки к техническим собеседованиям с возможностью фильтрации, просмотра и навигации по вопросам.

🚀 О проекте

Это SPA-приложение, разработанное на React + TypeScript, которое позволяет:
• просматривать список вопросов
• фильтровать по параметрам (навыки, сложность, рейтинг)
• открывать ответы
• взаимодействовать с UI через URL (все фильтры синхронизированы с query-параметрами)

🛠️ Технологии
• React
• TypeScript
• SCSS
• React Router

🧠 Особенности:
• централизованная работа с API
• управление состоянием через URL
• переиспользуемые компоненты
• строгая типизация

📦 Функционал
• 🔍 Фильтрация вопросов
• 📄 Пагинация
• 📊 Отображение сложности и рейтинга
• 📂 Открытие ответов
• 📱 Адаптивная верстка
• ⚡ Skeleton loading
• ❌ Обработка ошибок

▶️ Установка и запуск
npm install
npm run dev
